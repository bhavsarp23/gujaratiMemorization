# Gujarati Memorization

A desktop application used for practicing Gujarati text memorization, also known as *mukhpath*. The app quizzes the user line-by-line from a user-defined text file and grades the user based on accuracy.

The application is written in Python and uses the Kivy GUI framework. It supports English alphabet (ASCII) to Gujarati conversion import through the Harvard-Kyoto transliteration method, allowing the user to use only the characters on their keyboard.

## Features

- Memorization practice using user-defined text modules
- Line-by-line prompting and evaluation
- Automatic grading based on recall accuracy
- Gujarati input via Harvard–Kyoto transliteration
- Desktop GUI built with Kivy
